# MAFERTASAN

Sitio web estático preparado para desplegar en Vercel. No requiere instalación de dependencias ni proceso de compilación.

## Despliegue

Importa esta carpeta como proyecto en Vercel. Usa la raíz del proyecto como directorio de salida; no hace falta comando de construcción.

## Configuración pendiente

En `index.html`, configura los valores de `MAFERTASAN_CONFIG` con los datos reales de WhatsApp, correo, teléfono, dirección y horario. Los precios específicos aún no están cargados. El formulario valida la solicitud en el navegador, pero no transmite ni almacena datos hasta conectarlo a un servicio receptor y adaptar la política de privacidad.

Las imágenes de portada se sirven desde Unsplash. Para autoalojarlas, reemplaza el enlace de imagen por un archivo local.
